IRANIAN MIGHT - بسته آماده ساخت APK اندروید

این پروژه با Python و Kivy پیاده‌سازی شده و برای ساخت APK اندروید از Buildozer استفاده می‌کند.

امکانات فعلی:
- ورود و ثبت‌نام
- دانشنامه و جست‌وجوی زندگی‌نامه‌ها
- دفتر یادداشت شخصی
- تنظیمات و تغییر رمز عبور
- ذخیره‌سازی محلی اطلاعات با SQLite

روش ساخت APK با GitHub:
1) یک مخزن جدید در GitHub بسازید.
2) تمام محتویات این پوشه، از جمله پوشه مخفی .github، را در مخزن بارگذاری کنید.
3) در GitHub وارد زبانه Actions شوید.
4) گردش‌کار Build Android APK را انتخاب کنید و Run workflow را بزنید.
5) پس از پایان موفق، در صفحه همان اجرا، از بخش Artifacts فایل IRANIAN-MIGHT-APK را دانلود کنید. فایل APK داخل ZIP دانلودشده است.
6) APK را به گوشی اندرویدی منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را فعال کنید.

نکات:
- این بسته سورس و گردش‌کار ساخت است، نه APK کامپایل‌شده.
- ساخت APK در GitHub Actions به اینترنت نیاز دارد و ممکن است چندین دقیقه طول بکشد.
- حساب‌ها و یادداشت‌های قبلی رایانه منتقل نمی‌شوند؛ پایگاه داده روی گوشی جداگانه ساخته می‌شود.
- فایل‌های تصویری زندگی‌نامه‌ها در فایل‌های ارسالی وجود نداشتند و نسخه فعلی رابط از آن تصاویر استفاده نمی‌کند.
- این نسخه دستیار هوش مصنوعی ندارد.
